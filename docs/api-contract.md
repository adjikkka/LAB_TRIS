# API-контракт

API системы предоставляет HTTP-интерфейс между клиентским приложением Vue 3
и серверной частью ASP.NET Core.

Клиент Vue не обращается к PostgreSQL напрямую.
Все операции с данными выполняются через ASP.NET Core API.

## 1. Получение списка обращений

### GET /api/tickets

Возвращает список всех обращений жильцов.

Тело запроса отсутствует.

Успешный ответ:

**HTTP 200 OK**
