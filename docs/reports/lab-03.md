## 1. Цель

Поднять в репозитории приложение Vue 3 + Vite (JavaScript, без TypeScript),
которое запускается командой `npm run dev` на порту 5173 и показывает три
экрана: список обращений, форму создания и вход. Кнопки на этом этапе могли
ничего не сохранять — важно, чтобы сосед по README открыл те же экраны.

## 2. Что сделали

1. Проверили инструменты: `node -v`, `npm -v` (Node.js LTS).
2. Создали проект в корне репозитория, рядом с `/docs`: `npm create vue@latest frontend` (без TypeScript, без Pinia, без тестов).
3. Установили зависимости (`npm install`) и запустили dev-сервер (`npm run dev`).
4. Сделали экран списка: таблица с номером, темой, комнатой и статусом, строки выводятся через `v-for` с `:key="item.id"`, минимум две тестовые записи.
5. Сделали экран создания: `form` с полями `title`, `roomId`, `description`, у каждого поля связанный `label`, первое поле получает фокус (`autofocus`).
6. Сделали экран входа: `form` с логином и паролем (заготовка без настоящей проверки).
7. Переключение экранов — кнопки в шапке и `v-if`, одновременно показан только один экран.
8. Имена полей взяты из ЛР2: `title`, `roomId`, `description` (термин курса `siteId` в теме называется «Комната» — соответствие зафиксировано в `docs/data-model.md`).
9. Статусы — только из набора курса: `New`, `InProgress`, `Closed`, `Cancelled`.
10. Добавили `node_modules` и `dist` в `.gitignore`, убедились, что папка не попала в коммит.
