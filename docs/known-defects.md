# Известные дефекты и ограничения (ЛР12–13)

Честный список того, что система умеет и чего она не делает.
Формат карточки — из методички ЛР13. Исправления приоритетных дефектов
проводятся до защиты; статус «закрыт» — только после повторного прогона.

## A. Учебные ограничения (сознательные, не дефекты)

- **A-01. Генерация номера без защиты от гонки.** Номер `ОБР-2026-NNN`
  считается запросом максимума по таблице. При одновременном создании двух
  обращений возможен повтор номера → 500 от уникального индекса.
  Для учебного контура принято; в ВКР — последовательность/транзакция.
- **A-02. JWT-ключ по умолчанию в Development.** Если `Jwt:Key` не задан
  через user-secrets, используется ключ из `AuthOptions.DevFallbackKey`.
  Для курса допустимо; в настоящем контуре — секрет из конфигурации.
- **A-03. Токен в localStorage.** Для учебного контура допустимо
  (методичка ЛР11), банковским уровнем не является.
- **A-04. История смен статусов не хранится.** Видно только текущий
  статус; «кто и когда перевёл» не записывается (запас под ВКР — KPI).
- **A-05. Комнату выбирают числом.** На форме `roomId` — числовое поле
  из методички ЛР3/ЛР5; несуществующий номер отклоняет сервер (400
  «Комната не найдена»), список комнат для выпадающего списка не загружается.
- **A-06. Комендант отменяет только `New`.** После начала работ отменить
  нельзя (по матрице ролей); закрыть работу может только исполнитель.
- **A-07. Регистрация и «забыли пароль» не делаются.** Три учётки
  создаются seed'ом — по методичке ЛР11.

## B. Карточки дефектов

### D-01. Mock остался включённым — запросы не доходят до API
- Шаги / ожидали / получили: открываю список; ожидаю данные из API; список
  показывает учебные данные mock'а, в Network нет запроса на порт 5000.
- Причина и исправление: `VITE_USE_MOCK=true` в `.env`. Исправление:
  выставить `VITE_USE_MOCK=false`, перезапустить `npm run dev`.
- Повторная проверка: в Network видны запросы к `http://localhost:5000/api/tickets`.
- Статус: закрыт (проверить при вашем прогоне).

### D-02. CORS: запрос виден, ответ приложение не получает
- Шаги / ожидали / получили: запрос в Network красный, статуса нет;
  Swagger отвечает.
- Причина и исправление: origin 5173 не разрешён. Исправление: политика
  `Frontend` (`WithOrigins("http://localhost:5173")`) в `Program.cs`.
- Повторная проверка: список и создание работают с экрана Vue.
- Статус: закрыт (проверить при вашем прогоне).

### D-03. После рестарта API «исчезли» данные
- Шаги / ожидали / получили: создал обращение, перезапустил `dotnet run`,
  список пуст.
- Причина и исправление: в ЛР8 данные в памяти — это ожидаемо до ЛР10;
  после ЛР10 причина — миграции не применены (`dotnet ef database update`)
  или строка подключения смотрит в другую базу, чем открытая в pgAdmin.
- Повторная проверка: рестарт-тест ЛР10 — тот же id до и после рестарта.
- Статус: проверить при прогоне.
